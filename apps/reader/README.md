# PaperLens

論文を読みながら、1 文ごとの対訳と、訳・用語・数式・読解メモを Markdown のノートに残すアプリです。
旧 LogiXiv（1 文単位の対訳リーダー）の文分割と対訳を取り込み、1 つのアプリにまとめました。

- 中央に論文の PDF、右側に 1 文ごとの対訳と、選んだ箇所の訳、用語の説明、TeX 形式の数式、読解メモを表示します。
- PDF は取り込むと 1 文ずつに分けます。GROBID があれば使い、無ければ pdf.js で簡易に分けます。全文の訳は Claude が MCP 経由で入れます。
- 記録はテンプレートから作った読解ノート（note.md）に書き込みます。保存先フォルダは Obsidian の保管庫としてそのまま開けます。
- データはすべて保存先フォルダの普通のファイルです。データベースは使いません。
- MCP サーバーを登録すると、Claude Desktop や Claude Code などの AI エージェントが、画面と同じ操作（取り込み、本文の読み取り、全文の対訳、マーカーと訳、用語、数式、記録欄の入力、読解の段階の変更）を行えます。

構成は [SecOwl](https://github.com/nico0748/secowl) と同じです。ローカルサーバー（127.0.0.1 だけで待ち受け）が保存先フォルダを読み書きし、画面はブラウザかデスクトップ版（Electron）で表示します。MCP サーバーは同じ処理を直接呼ぶため、アプリを起動していなくても使えます。

## 必要なもの

| もの | 用途 | 備考 |
| --- | --- | --- |
| Node.js 22.6 以上 | アプリと MCP サーバーの実行 | `node -v` で確認できます |
| GROBID（Docker） | 1 文ずつの正確な区切りと PDF 上の位置 | 強く推奨します。無くても簡易解析で動きますが、精度は明確に落ちます |
| Claude の API キー | 画面からの訳・用語の説明・数式の書き起こし | 任意です。無くても手で入力できます。全文の対訳は MCP 経由なので不要です |

## 実行方法

### 1. 取得と準備

PaperLens 本体はリポジトリの `apps/reader` にあります（リポジトリ名は旧名の LogiXiv のままです）。依存パッケージはリポジトリの最上位でまとめて入れ、共有パッケージ（`packages/core`、`packages/server`）を先にビルドします。

```bash
git clone https://github.com/nico0748/LogiXiv.git
cd LogiXiv
npm install
npm run build
cd apps/reader
```

GROBID を使う場合は、リポジトリの最上位で起動しておきます。

```bash
docker compose -f docker/grobid.yml up -d      # http://localhost:8070
```

別のホストの GROBID を使う場合は、環境変数 `PAPERLENS_GROBID_URL`（旧名 `LOGIXIV_GROBID_URL` も使えます）で指定します。

以降のコマンドは `apps/reader` で実行します。

### 2. 起動する

目的に合わせて、次の4つから選んでください。

#### デスクトップ版で動かす（普段使いの場合）

```bash
npm run app
```

ビルドしてから PaperLens のウィンドウを開きます。mac では Electron.app を `PaperLens.app` という名前で写してから起動するので（`scripts/electron.mjs`。初回だけ数秒かかります）、Dock やメニューバーにも PaperLens と出ます。保存先は、初回は `apps/reader/data` です。設定画面の「別のフォルダを選ぶ」で変えられます。
配布用のアプリ（.dmg など）を作るときは `npm run dist` を実行します。`release/` にできます。配布用のアプリでは、保存先の初期値が「書類」フォルダの `PaperLens` になります。

#### ブラウザで動かす

```bash
npm run build
npm start
```

表示された URL（初期設定では http://127.0.0.1:5175 ）をブラウザで開きます。止めるときは `Ctrl + C` を押します。
ポートは環境変数 `PAPERLENS_PORT` で変えられます。

#### 開発サーバーで動かす（コードを変更しながら使う場合）

```bash
npm run dev
```

http://localhost:5173 を開きます。画面のコードを保存すると自動で反映され、サーバーのコードを保存するとサーバーが再起動します。

#### 1つの HTML ファイルにまとめる（サーバーを立てずに試す場合）

```bash
npm run build:single
```

`dist-single/index.html` ができます。Chrome か Edge で直接開くと、ブラウザで選んだフォルダに保存して動きます。
この形では対訳（1 文ずつの解析）、MCP サーバー、保存先の自動反映は使えません。

### 3. 使い始める

1. 左端のリボンの「論文一覧」（`⌘/Ctrl + \`）を開き、PDF を取り込みます（ドロップでも取り込めます）。取り込むと、テンプレートから読解ノートを作り、1 文ずつへの解析を始めます。
   一覧の上の「論文を追加」から「URL から追加」を選ぶと、PDF の URL か arXiv の番号（例 2410.12345）から取り込めます。arXiv の論文は、題名・著者・年も自動で入ります。
   1 つの HTML ファイルにまとめた版では、URL からは取り込めません。
2. 右側の「対訳」タブに文が並びます。カードを押すと PDF のその位置へ、PDF 上の文の枠を押すとそのカードへ移ります。`j` / `k` で前後の文へ、`n` で次の未訳の文へ移ります。
   カードでは、訳の手直し、メモ、「訳す対象から外す」、次の文との結合、文の分割ができます。解析方式（GROBID / 簡易解析）と崩れの疑いは、タブの上部とステータスバーに出ます。
3. 全文の訳は、MCP サーバーを登録した Claude に頼みます（「AI エージェントから使う」を参照）。訳は画面にすぐ反映されます。
4. PDF の文を選択すると、次の操作が出ます。
   - 色の丸: その色のマーカーを引く
   - 訳す: 選んだ文を日本語に訳す
   - 用語を調べる: 選んだ語の説明を作る
   - 数式にする: 選んだ数式を TeX に書き起こす
5. 右側の「記録」タブに読解メモを入力します。入力は note.md に自動で保存されます。
   タブの最上部の「書誌情報」で題名・著者・年・掲載先・DOI を直せます。「BibTeX をコピー」で BibTeX をコピーできます。
6. 論文一覧の検索欄で、題名・著者・年と、ノートの中を探せます。段階のチップで一覧を絞り込めます。
   一覧の見出しの右の「並び順」で、追加日・題名・発行年・読解の段階の順に並べ替えられます。選んだ並び順は次に開いたときも使います。
   ノートの frontmatter の `tags` は、一覧の行の下に #タグ として出ます。押すとそのタグの論文だけになります。検索欄に `#ml` のように打っても同じです。
   一覧の下の「BibTeX を書き出す」で、表示している論文の BibTeX を 1 つの .bib ファイルにまとめて保存できます。絞り込み中は、表示している論文だけを書き出します。引用キーが重なったときは、2 つ目から末尾に a, b, … を付けます。
7. PDF の上のページ番号の欄に数字を入れて Enter を押すと、そのページへ移ります。論文を開き直すと、前回の位置から表示します。
8. 左端の「リスト」（`⌘/Ctrl + Shift + L`）で、すべての論文の用語（対訳の用語集を含む）と数式を、単語帳と数式帳として引けます。
9. 左端の「グラフ」で、論文と用語のつながりを見られます。
10. 左端の「発表スライドと論文の対応」で、論文発表会のスライド（PDF か PPTX）を論文の左に並べられます。
    - スライドをドロップするか「スライドを追加」で取り込みます。PPTX は PDF に変換して表示します（LibreOffice か Keynote が必要です。無ければ PowerPoint などで PDF に書き出してから取り込んでください）。
    - 「囲む」（`R`）でスライドの一部をドラッグして囲むと、グループができます。名前は「Markup-ページ.番号」です（3 ページ目で 2 個目に囲んだ部分は Markup-03.02）。番号は、途中のグループを消してもずれません。
    - グループを選んでいる間に、論文の文をドラッグで選んで「文章としてリンク」を押すか、「図」（`F`）・「数式」（`E`）で論文の範囲を囲むと、リンクできます。1 つのグループから何か所にでもリンクできます。
    - グループと論文の該当箇所は、グループの色の線でつながります。片方が画面の外にあるときは、端まで点線で引きます。「選んだ線だけ」で、選んでいるグループの線だけを出せます。
    - グループの名前の札は、グループにカーソルを乗せたとき（かフォーカスしたとき）だけ出ます。論文側はふだん左上の小さな色の点だけで、点に乗ると札になります。
    - 札の消すボタン（ごみ箱）か、グループを選んで `Delete` / `Backspace` で、グループを消せます。スライドと論文のどちらの側から消しても、グループごと（スライドの四角と論文のリンクの両方）消えます。消したあと 8 秒ほど出る「元に戻す」か `⌘Z`（`Ctrl+Z`）で、同じ名前のまま戻せます。
    - 上の「スライド」「補足情報」のタブで、[スライド | 論文] と [論文 | 補足情報] を切り替えられます（横スクロールか `[` / `]` でも切り替わります）。論文の幅は変わりません。補足情報には、論文の画面の右サイドバーと同じ対訳・訳・用語・数式・記録が出て、用語や数式の場所を押すと論文の側がそこへ移ります（数式を囲んで場所を決めるのは論文の画面で行ってください）。選んだ側は次に開いたときも同じです。
    - 右側にグループの一覧が出ます。メモ、色、リンクの種類を直したり、リンクやグループを消したりできます。対応はノートの「発表スライドとの対応」にも書き出します。
    - 発表のときは「発表」（`P`）で、スライドと論文を並べた画面（線も含む）を別の窓に全画面で映し、元の窓には台本（スライドの順に、グループのメモとリンクした論文の箇所）を出します。外部ディスプレイがあれば、発表の窓はそちらに出ます。台本でページやグループを押すと発表の窓がそこへ動き、`←` / `→`（`PageUp` / `PageDown`）でスライドを送れます。「発表を終える」か `P` で元に戻ります。
    - 別の窓を開けないとき（ブラウザがポップアップを止めたときなど）は、これまでどおりこの画面を全画面にします。欄の見出しと道具の帯は隠れ、画面の上の端にマウスを動かすと道具の帯が出ます。`Esc` か `P` で元に戻ります。

サイドバーの開閉と幅は、保存先の `.paperlens/workspace.json` に保存します。キーボード操作の一覧は、左端の「ヘルプ」にあります。

Obsidian で保存先フォルダを開いてノートを書き換えても、PaperLens の画面にすぐ反映されます。

### 4. Claude を使う（任意）

左端の「設定」から「API キーとモデルを設定する」を押し、API キーを入力します。

- キーはブラウザにだけ保存し、保存先フォルダには書き込みません。
- Claude に送るのは、選択した範囲の文、その前後の本文、論文の題名です。数式では選択範囲の画像も送ります。PDF 全体は送りません。
- 初期設定のモデルは `claude-opus-5-5` です。

## AI エージェントから使う（MCP）

左端の「設定」の「AI エージェント（MCP）」に、この端末での登録方法が表示されます。「コピーする」を押して貼り付けてください。

### Claude Code

```bash
claude mcp add paperlens -e PAPERLENS_CONFIG=<apps/reader>/paperlens.config.json -- node <apps/reader>/dist-server/mcp.js
```

### Claude Desktop

設定ファイル（macOS は `~/Library/Application Support/Claude/claude_desktop_config.json`）の `mcpServers` に次を加え、Claude Desktop を再起動します。

```json
{
  "mcpServers": {
    "paperlens": {
      "command": "node",
      "args": ["<apps/reader>/dist-server/mcp.js"],
      "env": { "PAPERLENS_CONFIG": "<apps/reader>/paperlens.config.json" }
    }
  }
}
```

`<apps/reader>` は実際のパスに置き換えてください。設定画面に表示されるものは置き換え済みです。
`dist-server/mcp.js` は `npm run build` で作られます。ビルド前は `node --experimental-strip-types mcp/main.ts` でも動きます。

### できること

| ツール | 内容 |
| --- | --- |
| `get_settings` | 保存先、フォルダ構成、読解の段階、テンプレートの記録欄 |
| `list_papers` / `get_paper` / `get_note` | 論文の一覧、論文1本の記録（記録欄・マーカー・用語・数式）、ノートの本文 |
| `get_bibtex` | 論文の BibTeX（画面の「BibTeX をコピー」と同じ内容） |
| `read_paper_text` / `find_in_paper` | PDF の本文をページごとに読む、本文の中を探す |
| `get_page_image` | 論文かスライドの 1 ページを画像で見る（一部の切り出しもできる。数式・図・画像だけのスライド向け） |
| `get_lists` | 全論文の単語帳と数式帳（画面の「リスト」と同じ） |
| `search_notes` / `get_graph` | すべてのノートの横断検索、論文と用語のつながり |
| `import_paper` | 端末の PDF や URL（arXiv など）から取り込む |
| `set_fields` / `set_status` / `set_meta` | 記録欄、読解の段階、書誌情報（著者・年など）を書く。著者など一覧の項目は配列で渡す |
| `add_highlight` / `update_highlight` | 本文の文にマーカーと訳を付ける。PDF の該当位置にも色が付く。引く場所も直せる |
| `add_term` / `update_term` / `add_equation` / `update_equation` | 用語と数式を登録する・直す |
| `remove_annotation` | マーカー・用語・数式を消す |
| `get_template` / `set_template` / `reset_template` | テンプレートを読む、書き換える、初期状態に戻す |
| `set_data_root` | 保存先を変える |
| `get_sentence_outline` / `get_sentences` / `search_sentences` | 対訳の概要（解析方式・進捗・用語集）、文の取得、対訳の中の検索 |
| `get_translation_batch` / `set_translations` | 全文翻訳の窓を受け取り、訳をまとめて書き戻す |
| `parse_sentences` | PDF を 1 文ずつに分ける・分け直す（訳とメモは引き継ぎます） |
| `add_sentence_note` / `update_glossary` / `skip_sentences` / `fix_sentence_boundary` | 文のメモ、訳語の統一、訳さない記録、区切りの直し |
| `remove_sentence_note` / `remove_glossary_terms` / `clear_translations` | 文のメモを消す、用語集から 1 語ずつ消す、訳を消す（人が直した訳は確かめてからだけ） |
| `import_slides` | 発表スライド（PDF か PPTX の絶対パス）を取り込む。差し替えても囲んだグループは残る |
| `get_slide_markups` / `read_slide_text` | 発表スライドで囲んだグループの一覧（名前、範囲、色、四角の中の文字、論文へのリンク）、スライドの文字 |
| `add_slide_markup` | スライドを囲んでグループを作る（範囲か、スライドの文字列で） |
| `link_slide_markup` / `update_slide_link` / `unlink_slide_markup` | グループを論文の文章・図・数式につなぐ、リンクの種類を直す、外す |
| `update_slide_markup` / `set_slide_markup_memo` | グループのメモ・色・範囲を直す |
| `delete_slide_markup` / `restore_slide_markup` | グループを消す、消したグループを戻す |

ほかに、段階を追って論文を読む `read_paper`、1 文ずつ全文を訳す `translate_paper`、読んだ論文をふり返る `review_notes` のプロンプトがあります。対訳のツールの詳しい設計は [../../docs/mcp.md](../../docs/mcp.md) にあります。読解ノートは `paperlens://papers/<論文ID>/note.md` の資料としても読めます。

- 環境変数 `PAPERLENS_MCP_READONLY=1` を付けると、読み取りのツールだけを公開します。設定画面の「読み取りだけを許可する」で、その設定を作れます。
- アプリを起動している間は、エージェントの変更が画面にすぐ反映されます。画面とエージェントが同じ論文を同時に編集しても、互いの変更を消しません。

## 保存先

保存先フォルダは次の順に決まります。

1. 環境変数 `PAPERLENS_DATA`
2. 設定ファイルの `dataRoot`（`PAPERLENS_CONFIG`、無ければ `apps/reader/paperlens.config.json`。デスクトップ版はアプリのデータフォルダ）
3. 初期値（`apps/reader/data`）

設定画面で保存先を変えると設定ファイルに書き込みます。MCP サーバーも同じ設定ファイルを読むため、AI エージェントも新しい保存先に付いてきます。

```
<保存先>/
  .paperlens/workspace.json     画面の配置（サイドバーの開閉・幅・開いている論文）
  _templates/reading-note.md    読解ノートのテンプレート
  papers/20261012-attention/
    paper.pdf                   取り込んだ PDF
    note.md                     読解ノート
    paperlens.json              マーカー・用語・数式（位置などの補助データ）
    sentences.json              1 文ずつの対訳（文・位置・訳・メモ・用語集）
    sentences.status.json       解析の進み具合（解析中・失敗・完了）
```

## 保管庫を共有するとき

arXiv などから取り込んだ PDF は、多くの場合、再配布が許されていません。保管庫を公開の Git リポジトリにする場合は、PDF を入れないでください。
保管庫の `.gitignore` に次の行を書くと、ノートだけを共有できます。

```
papers/*/paper.pdf
```

## テンプレートを変える

保存先の `_templates/reading-note.md` を編集すると、これから取り込む論文のノートに反映されます。
「設定」の「テンプレートを編集する」からも編集できます。
入力欄は次の形で書きます。直前の `##` 見出しが、記録タブでのまとまり（読解の段階）になります。

```markdown
### 一言でいうと
<!-- field: summary | 一言でいうと | 何をして何が分かったかを1〜2文で書く -->
<!-- /field -->
```

アプリと AI エージェントは `<!-- field -->` と `<!-- list -->` で囲んだ範囲だけを書き換えます。範囲の外に書いた内容は変更しません。
詳しい仕様は [docs/design.md](docs/design.md) にあります。

## 開発者向けのコマンド

| コマンド | 内容 |
| --- | --- |
| `npm test` | 単体テスト（テンプレート、frontmatter、BibTeX、検索、前回の位置、URL 取得の安全策、注釈の差分、サーバーの API、対訳の保存と解析、MCP のツール、画面の配置、リスト） |
| `npx tsc --noEmit` | 型を検査する。最上位の `npm run typecheck` にも含まれます |
| `npm run e2e` | ヘッドレス Chromium で操作を確認する。先に `npm run build:single` と `npm run build` を実行してください。発表スライドの画面は `e2e/slides.mjs` |
| `npm run sample` | お試し用のサンプル PDF（`src/demo/sample.pdf`）を作り直す |

`npm run e2e` を初めて実行する前に、`npx playwright install chromium` でブラウザを入れてください。

```
server/      ローカルサーバー（API、保存先の見張り、PDF の本文取り出し、対訳の保存と解析 sentences.ts）
mcp/         MCP サーバー（tools.ts に読解ノートのツール、sentenceTools.ts に対訳のツール、slideTools.ts に発表スライドのツール）
electron/    デスクトップ版
src/         画面（React）。src/components/shell/ に Obsidian 風の枠（リボン・サイドバー・ステータスバー）、
             src/components/sentences/ に対訳。src/lib/ の論文フォルダの処理はサーバーと MCP からも使う
```

## うまく動かないとき

| 症状 | 対処 |
| --- | --- |
| ブラウザに「画面がまだビルドされていません」と出る | `npm run build` を実行してから `npm start` を実行してください |
| Claude Desktop にツールが出てこない | 設定ファイルの JSON が正しいか確かめ、Claude Desktop を再起動してください。`node` が見つからない場合は、`command` を `which node` の結果に置き換えてください |
| エージェントが別のフォルダを見ている | 設定画面に表示される登録方法で登録し直してください。保存先を `PAPERLENS_DATA` で固定している場合は、その値がアプリとそろっているか確かめてください |
| 訳を頼むと「API キーが正しくありません」と表示される | 設定画面でキーを入れ直してください |
| PDF の文を選択できない | 画像だけの PDF（スキャンした PDF）は文字情報が無いため選択できません。OCR をかけてから取り込んでください |
| 大学や会社のネットワークで、URL から取り込めない | プロキシの内側では URL から取得できません。ブラウザで PDF を保存し、論文一覧の「PDF を追加」で取り込んでください |
| 構内だけで公開されている機関リポジトリの URL が「ローカルネットワークの URL は使えません」と断られる | 環境変数 `PAPERLENS_ALLOW_PRIVATE_URLS=1` を付けてサーバー（`npm start`）か MCP サーバーを起動してください。端末内やローカルネットワークの URL も取得するようになるため、必要なときだけ付けてください |
| 対訳が「簡易解析」になる | GROBID に届いていません。`docker compose -f docker/grobid.yml up -d` で起動してから、対訳タブの「解析し直す」で GROBID を選んでください |
| 対訳の文が途中で切れている、2 段組の左右が混ざっている | 簡易解析の限界です。GROBID で解析し直してください。リポジトリの最上位の README の「簡易解析で何が起きうるか」に詳しく書いています |
| PPTX のスライドを取り込むと「変換できませんでした」と出る | LibreOffice か Keynote が必要です。どちらも無ければ、PowerPoint などで PDF に書き出してから取り込んでください。LibreOffice の場所は環境変数 `PAPERLENS_SOFFICE` でも指定できます。Keynote は初回に「オートメーション」の許可を求めます |
| 対訳を単一の HTML に書き出したい | まだ PaperLens 本体にはありません。旧 LogiXiv の Web 画面（`apps/web`。リポジトリの最上位で `npm start`）で行えます |
