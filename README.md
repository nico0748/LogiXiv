# PaperLens

論文を読みながら、訳・用語・数式・読解メモを Markdown のノートに残すアプリです。

- 中央に論文の PDF、右側に選んだ文の訳、用語の説明、TeX 形式の数式を表示します。
- 記録はテンプレートから作った読解ノート（note.md）に書き込みます。Obsidian でもそのまま開けます。
- データはすべて、選んだフォルダの中に普通のファイルとして保存します。

## 必要なもの

| もの | 用途 | 備考 |
| --- | --- | --- |
| Node.js 20 以上 | ビルドと開発サーバー | `node -v` で確認できます |
| Chrome または Edge | アプリの表示 | フォルダへの保存に必要です。Safari と Firefox はフォルダの読み書きに対応していません |
| Claude の API キー | 訳・用語の説明・数式の書き起こし | 任意です。無くても手で入力できます。[Anthropic Console](https://console.anthropic.com/) で発行します |

## 実行方法

### 1. 取得と準備

```bash
git clone https://github.com/nico0748/LogiXiv.git
cd LogiXiv
npm install
```

### 2. 起動する

目的に合わせて、次の3つから選んでください。

#### 開発サーバーで動かす（コードを変更しながら使う場合）

```bash
npm run dev
```

表示された URL（初期設定では http://localhost:5173 ）を Chrome か Edge で開きます。
コードを保存すると画面に自動で反映されます。止めるときは `Ctrl + C` を押します。

#### ビルドして動かす（普段使いの場合）

```bash
npm run build
npm run preview
```

表示された URL（初期設定では http://localhost:4173 ）を開きます。

#### 1つの HTML ファイルにまとめる（サーバーを立てずに使う場合）

```bash
npm run build:single
```

`dist-single/index.html` ができます。このファイルを Chrome か Edge で直接開けば動きます。
ほかの人に渡すときも、このファイル1つで足ります。

### 3. 使い始める

1. 最初の画面で「保管庫にするフォルダを選ぶ」を押し、ノートを置くフォルダを選びます。
   ブラウザがフォルダの編集を許可するか尋ねるので、許可してください。
   Obsidian の保管庫にしているフォルダを選ぶと、Obsidian からも同じノートを開けます。
2. 左上の「PDF を追加」で論文を取り込みます。
3. PDF の文を選択すると、次の操作が出ます。
   - 色の丸: その色のマーカーを引く
   - 訳す: 選んだ文を日本語に訳す
   - 用語を調べる: 選んだ語の説明を作る
   - 数式にする: 選んだ数式を TeX に書き起こす
4. 右側の「記録」タブに読解メモを入力します。入力は note.md に自動で保存されます。

保存先のフォルダを選ばずに試すときは、「サンプルの論文で試す」を押してください。この場合、内容はページを閉じると消えます。

次回からは「前回のフォルダを開く」で同じフォルダを開けます。

### 4. Claude を使う（任意）

左下の「Claude の設定」で API キーを入力します。

- キーはブラウザにだけ保存し、フォルダには書き込みません。
- Claude に送るのは、選択した範囲の文、その前後の本文、論文の題名です。数式では選択範囲の画像も送ります。PDF 全体は送りません。
- 初期設定のモデルは `claude-opus-5-5` です。設定画面で変更できます。

## 保存されるファイル

```
<選んだフォルダ>/
  _templates/reading-note.md    読解ノートのテンプレート
  papers/20261012-attention/
    paper.pdf                   取り込んだ PDF
    note.md                     読解ノート
    paperlens.json              マーカーの位置などの補助データ
```

## テンプレートを変える

保管庫の `_templates/reading-note.md` を編集すると、これから取り込む論文のノートに反映されます。
アプリの左下にある「テンプレートを編集」からも編集できます。
入力欄は次の形で書きます。直前の `##` 見出しが、記録タブでのまとまりになります。

```markdown
### 一言でいうと
<!-- field: summary | 一言でいうと | 何をして何が分かったかを1〜2文で書く -->
<!-- /field -->
```

アプリは `<!-- field -->` と `<!-- list -->` で囲んだ範囲だけを書き換えます。範囲の外に書いた内容は変更しません。
詳しい仕様は [docs/design.md](docs/design.md) にあります。

## 開発者向けのコマンド

| コマンド | 内容 |
| --- | --- |
| `npm test` | 単体テストを実行する |
| `npm run typecheck` | 型を検査する |
| `npm run e2e` | ヘッドレス Chromium で操作を確認する。先に `npm run build:single` を実行してください |
| `npm run sample` | お試し用のサンプル PDF（`src/demo/sample.pdf`）を作り直す |

`npm run e2e` を初めて実行する前に、`npx playwright install chromium` でブラウザを入れてください。

## うまく動かないとき

| 症状 | 対処 |
| --- | --- |
| 「保管庫にするフォルダを選ぶ」が表示されない | Safari か Firefox で開いています。Chrome か Edge で開いてください |
| 「前回のフォルダを開く」で開けない | フォルダを移動または削除した可能性があります。「保管庫にするフォルダを選ぶ」から選び直してください |
| 訳を頼むと「API キーが正しくありません」と表示される | 「Claude の設定」でキーを入れ直してください |
| PDF の文を選択できない | 画像だけの PDF（スキャンした PDF）は文字情報が無いため選択できません。OCR をかけてから取り込んでください |
